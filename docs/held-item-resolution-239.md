# S15P31C106-239 기존 보류 이력 조회

규칙 이력의 기존 보류 이력 탭은 이전에 승인 반영 중 저장된 개별 보류 건을 보여 준다. 기존 경로 `/admin/rules/{proposalId}/history?view=held`를 사용한다.

- 056 목록·057 상세는 기존 경로와 응답으로 조회한다. `HELD`·`APPROVED`·`AUTO_RESOLVED`·`DISMISSED`는 당시 기록된 상태다.
- 기존 보류 건 상세는 읽기 전용이다. 이력 조회로 보류 건이나 문제의 상태를 바꾸지 않는다.
- 신규 미연결과 현재 처리 상태는 문제 목록·상세(065·066)에서 확인한다. 수동 연결은 문제 상세의 058에서 저장하고 재검증 결과는 070에서 조회한다. [문제 API 계약](issue-query.md#수동-연결-058)

11월 7일에 확인한 [이전 058 초안](https://app.notion.com/p/405bdf14d2d881dea3d4dda5b646c3f6)은 보류 건의 승인·종결을 전제로 했다. !352에서 미연결을 문제로 일원화했고, 238은 이 결정을 반영해 문제의 수동 연결 API를 제공한다.
