# 408 문서 연결 후보 기본 상세 검증

- Jira: S15P31C106-408
- 기준 develop: `6b4b184`
- 브랜치: `fix/408-document-link-detail`

## 운영 후보 #901 읽기 전용 대조

2026-11-14 KST에 사용자가 로그인한 Chrome 세션으로 확인했다. 운영의 정확한 배포 커밋은 확인하지 않았다. 승인·보류·거절·검사 실행·저장 요청은 수행하지 않았다.

- `GET /api/v1/proposals/901`: `data` 조회 성공. 종류는 `DOCUMENT_LINK`, 개정 1, `PENDING`·`NOT_APPLIED`, `checkRequired=false`다.
- `GET /api/v1/proposals/901/options?revision=1`: `data=[]`다.
- 현재 운영 기본 탭에는 연결·변환 규칙 제목만 표시된다. 상세 정의를 펼치면 문서 내용·대상이 표시되어 기본 배치 문제를 재현했다.

| 표시 항목 | 실제 응답 필드 | 이번 구현과 대조 |
| --- | --- | --- |
| 문서 내용 | `evidence.originalText` | 문자열을 기본 화면에 표시한다. 원천 문서를 추가 조회하지 않는다. |
| 문서 식별 | `payload.documentId`, `evidence.documentLabel` | 서버가 제공한 문서 식별·이름을 표시한다. |
| 연결 대상 | `payload.targetObjectRef` | 제공된 참조를 표시한다. `targetLabels`는 #901 응답에 없으므로 새 이름을 추측하거나 따로 조회하지 않는다. |
| 판단 근거 | `evidence.reason` | 제공된 문장을 기본 화면에 표시한다. |
| 언급·강조 | `payload.mentionText`, `spanStart`, `spanEnd`, `expressionKind` | 확인된 언급과 원문 내 위치를 표시한다. |
| 관찰·시각 | `evidence.observations=[]`, `times` 1개 | 관찰 목록은 생략하고 제공된 시각 표현을 표시한다. |
| 판단 상태 | `holdRecommended=false`, `holdReason=null`, 대안 없음 | 미확정·복수 후보로 만들지 않는다. |

운영 원문·자격 증명·쿠키는 파일이나 테스트에 저장하지 않았다. 응답의 필드 형태만 합성 데이터로 재현하는 회귀 테스트를 추가했다. 정책·가림 자체의 정확성을 전수 검증한 결과는 아니다.

## 변경 범위

`DocumentLinkView`를 접힌 상세 밖의 기본 탭으로 옮기고 문서 후보의 탭을 문서 내용으로 표시한다. 판단 근거와 미제공 안내를 추가한다. 공백 문자열을 미제공으로 처리하되 원문의 값·위치는 변경하지 않는다.

384 접근 정책, 그룹·민감도 UI, 백엔드 업무 코드, API·DB·원천·인프라 설정은 변경하지 않았다. 기존 검토 결정 기능을 유지한다.

## 검증 기록

- 로컬 Chrome 합성 후보에서 기본 문서 내용 탭에 정보 추출 결과가 나타나는 것을 확인했다.
- 운영 응답과 구현 필드의 대조는 완료했으며, 수정 화면의 운영 배포 후 검증은 아직 수행하지 않았다.
- 전체 자동 검사와 독립 리뷰의 최종 결과는 MR 본문에 기록한다.

## 후속 경고 개선

사용자 요청으로 같은 브랜치에서 기존 프론트 경고도 보완했다.

- 재검증 비교 영역에서 결과·이력의 형제 컴포넌트가 실행 ID를 그대로 key로 써서 `20`·`42`가 겹쳤다. 발견·해결·현재 결과·이력별 접두사를 붙여 각각의 컴포넌트를 구분하고 실행 변경 시 초기화 동작을 유지했다.
- 기존 접수→완료→비교 및 해결 후 갱신 테스트에서 중복 key 경고를 실제 실패로 재현한 뒤 수정했다. 콘솔 출력을 숨기지 않고 경고 발생 여부를 확인한다.
- `App`에서 업무·관리 화면을 `React.lazy`로 분리하고 `Suspense`로 로딩 상태를 표시한다. 인증·역할 검사와 경로는 유지한다. 의존성 추가나 빌드 경고 한도 변경은 없다.
- production 빌드의 가장 큰 JS 파일은 951.16 kB에서 425.52 kB로 줄었다. 분리된 그래프는 244.64 kB, Agent는 186.66 kB이며 500 kB 초과 경고가 사라졌다. 전체 다운로드 합계가 이 비율로 줄었다는 뜻은 아니다.
- 기존 화면 이동·재검증·해결 테스트 57개와 production 빌드를 통과했다. 최종 전체 검사 및 추가 독립 리뷰 결과는 MR 본문에 기록한다.
