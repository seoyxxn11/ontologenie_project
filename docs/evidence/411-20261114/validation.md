## 구현

- 적용한 검색어(q), 객체 유형(objectTypeId), 속성 조건(propertyValues[코드]), 객체 목록 페이지(page)를 URL에서 읽고 쓴다. 객체 응답·원문을 브라우저 저장소에 보관하지 않는다.
- 객체·관계·연결 객체 선택은 이전 주소를 교체하지 않고 기록을 추가한다. 같은 선택의 중복 기록은 피한다. 연결 목록 페이지(relatedPage)도 URL로 복원한다.
- 검색 적용 시 첫 페이지로 이동하고 바뀐 조건이면 선택·관계 문맥을 해제한다. 입력만 수정할 때는 현재 결과·페이지·선택을 유지한다. 자동 페이지 범위 보정은 기존 기록을 교체한다.
- 유효하지 않은 ID·페이지는 안전한 기본값/범위로 처리하며, 알 수 없는 유형은 전체 유형으로 잘못 표시하지 않는다. API 권한 검사·가림은 기존 서버 계약을 따른다.
- 좁은 화면에서 상세를 긴 관계도보다 먼저 배치하고 상세 바로 보기 버튼을 제공한다. 이동 시 관계도 확장을 해제하고 상세에 포커스를 둔다. 기존 메뉴·AI 입력창은 변경하지 않는다.
