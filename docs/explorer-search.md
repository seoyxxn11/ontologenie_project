# 업무 데이터의 업무 코드 검색

API 076 `GET /api/v1/objects`의 `q` 검색은 화면에 표시된 업무 코드로 객체를 찾을 수 있어야 한다.

- 검색 대상은 권한 적용 후 표시 이름, 조회 가능한 원천 키의 개별 값, 조회 가능한 식별 속성 값이다.
- 원천 키는 목록의 `sourceKey`와 같은 권한 가림을 먼저 적용한다. 가린 값·분류되지 않아 숨긴 값·null은 검색 대상에 넣지 않는다.
- 원천 키 값은 `is_identifier` 설정이 없어도 검색한다. 표시 이름이 `1라인 3호 프레스`이고 보이는 원천 키 값이 `P103`인 설비를 `P103`·`p103`·`P10`으로 찾을 수 있다.
- 대소문자를 구분하지 않으며 앞뒤 공백을 제거한다. `%`·`_`는 와일드카드가 아닌 입력한 글자로 검색한다.
- 이름·원천 키·식별 속성의 정확한 일치를 부분 일치보다 먼저 정렬한다. 같은 우선순위에서는 기존 객체 ID 오름차순을 유지한다.
- 객체 유형·속성·기간·상태 조건, 데이터 접근 범위와 페이지네이션은 기존대로 함께 적용한다.

요청·응답 필드, URL, DB 스키마는 변경하지 않는다. 검색 범위 설명은 API 076 OpenAPI 원본에도 반영해야 한다. `.ai/references.md`의 Notion API 명세서는 연결된 계정에서 404로 조회되지 않아 이번 작업에서는 원본을 수정하지 못했다.
